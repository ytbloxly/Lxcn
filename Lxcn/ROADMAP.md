# Lxcn roadmap

## v0.1.0
- JavaScript interpreter and VS Code Run command
- `.lx`, `.lxc`, `.lxcn` file support
- Basic syntax highlighting and file icon theme
- Static/dynamic variables, constants and optional types
- Conditions, for loops, casts and type checks

## Next
- A dedicated lexer, parser and AST (replace the current source translator)
- Better source-line diagnostics and precise error locations
- Functions, arrays, objects and imports
- `while` and `foreach` loops
- Package manager and standalone CLI
- Debugging and formatting support
